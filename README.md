 Over dit project
Dit project richt zich niet primair op het eindresultaat, maar op mijn leerproces. Het doel is om te leren hoe het echt werkt, zodat ik het later nog eens zonder hulp/problemenn het zelf kan bouwen.

Belangrijkste leerpunten
Tijdens dit project heb ik de volgende concepten en technieken geleerd en toegepast:

require_once – Het importeren van bestanden zonder risico op dubbele inclusies.

__DIR__ – Gebruik van de constante voor padmanipulatie, om bestanden relatief en betrouwbaar te kunnen includeren.

Classes (OOP) – Toepassen van objectgeoriënteerd programmeren voor een gestructureerde en herbruikbare codebase.

Debug-bestand – Creëren en gebruiken van een apart debug systeem voor het loggen en analyseren van fouten.

Sessiebeëindiging in de applicatie – Het correct en veilig afsluiten van sessies vanuit de code en applicatie.

Foutmeldingen begrijpen en oplossen – analyseren en debuggen van PHP-foutmeldingen.
